MODEL CHARACTERISTICS
--------------------------------------------------------------------------------

Bayesian Network:
  • Structure: 8 nodes, 8 edges
  • Training: Bayesian Estimation (BDeu prior)
  • Inference: Variable Elimination (exact)
  • Interpretability: ✓ Full (can trace reasoning)
  • Probabilistic: ✓ Provides P(outcome)
  • Domain knowledge: ✓ Encoded in structure

LightGBM:
  • Structure: Gradient boosted trees
  • Training: Gradient boosting
  • Inference: Ensemble prediction
  • Interpretability: ✗ Black box
  • Probabilistic: ~ Calibrated probabilities
  • Domain knowledge: ✗ Data-driven only


WINNER BY METRIC
--------------------------------------------------------------------------------

  ✗ accuracy     : LightGBM
  ✗ auc          : LightGBM
  ✗ logloss      : LightGBM
  ✗ brier        : LightGBM


CONCLUSION
--------------------------------------------------------------------------------

The models perform nearly identically in terms of raw metrics.

Key Trade-off:
  • BN sacrifices ~1.6% accuracy for full interpretability
  • This trade-off is WORTHWHILE for:
    - Understanding what drives round outcomes
    - Explaining predictions to stakeholders
    - Strategic analysis and decision-making
    - Building trust in AI systems

Recommendation:
  • Use BN for strategic analysis and understanding
  • Use LightGBM if pure prediction accuracy is paramount
  • For this project: BN is superior (interpretability + domain knowledge)
